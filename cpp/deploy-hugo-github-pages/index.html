    I wanted a lightweight way to publish technical notes and design decisions without dealing with servers, frameworks, or ongoing maintenance.
    Hugo + GitHub Pages turned out to be the simplest and most robust solution.

    This post documents the exact steps I used to deploy this blog.

    Project Structure#

    After creating a Hugo site, the directory layout looks roughly like this:

    professionalcpp/ ├── content/ ├── themes/ ├── static/ ├── hugo.toml └── public/ # generated output (do not edit manually)

    All blog posts live under content/.
    The public/ directory is generated by Hugo and contains the final HTML/CSS.

    Step 1: Configure the Base URL#

    Since the site is hosted under a GitHub Pages subpath, the baseURL must be set correctly.

    In hugo.toml:

    baseURL = "https://<username>.github.io/<repo-name>/"
relativeURLs = true
canonifyURLs = true


## Step 2: Build the site

from the Project root:

    hugo

    This generates the static site into the public/ directory.

## Step 3: Create a GitHub repository

Create a public GitHub repository (for example, professionalcpp).

Do not add a README or .gitignore — keep it empty.

## Step 4: Publish using a 'gh-pages' Branch

The generated site is deployed from the public/ Directory

    cd public git init git branch -M gh-pages git remote add origin https://github.com//.git git add . git commit -m “Publish Hugo site” git push -f origin gh-pages

    
This branch contains only the generated static files.

## Step 5: Enable Github pages

In the GitHub repository settings:

Go to Settings → Pages

Source: Deploy from a branch

Branch: gh-pages

Folder: / (root)

After a short delay, the site becomes available at:

`https://<username>.github.io/<repo-name>/`

## Writing new Posts

New blog posts are simple Markdown files under:

`content/posts/`


Example front matter:

    title: “Stateless Motion Models for Estimation” date: 2026-02-05 tags: [“c++”, “simulation”, “estimation”]#

    
Rebuild and republish after adding content:

    hugo cd public git add . git commit -m “Update site” git push -f origin gh-pages
